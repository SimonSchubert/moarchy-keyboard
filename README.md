# moarchy-keyboard

An on-screen keyboard for the PinePhone running [mobileomarchy](../mobileomarchy):
Qt6 + QML, themed live from Omarchy's palette, rendered on the Mali-400.

Replaces squeekboard, which behaves correctly but ignores the theme and draws
through cairo on the CPU.

**Nothing is implemented yet.** Read [SPEC.md](SPEC.md) first — the acceptance
criteria are agreed before the code, not after.
